# Security Policy

## Supported versions

Security fixes are applied on the `main` branch.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/MaiconGambini/erpGolang/security/advisories/new) or contact the repository owner.

Include:

- Description of the issue and impact
- Steps to reproduce
- Affected endpoints or components

We aim to acknowledge reports within 7 days.

## Scope notes

- This is a portfolio / learning project, not a certified production ERP.
- Default seed credentials (`admin123`) are for local development only.
- Never deploy with example JWT secrets from `.env.example`.
